DevOps Automation Successful 🚀

This website is built, tested, packaged as a container and deployed automatically on every push to main.

The pipeline

  1. Lint HTML validation and Dockerfile linting
  2. Build Docker image (nginx, non-root)
  3. Test run the container and smoke-test every page
  4. Scan image vulnerability scan
  5. Deploy GitHub Pages and GitHub Container Registry
  6. Notify Slack message with the result
